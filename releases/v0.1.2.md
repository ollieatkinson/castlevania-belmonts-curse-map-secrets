Adds marker hover labels and fixes map-panel cleanup when travelling.

### What changed
- Hover a visible marker with the mouse or the game’s map cursor to see its name and category in a small native-font label. The icon gently enlarges and brightens.
- Labels distinguish health/mana hearts, attack/defence books, named equipment and passage types. Unknown completion and approximate locations are identified.
- Experience sources now have a separate toggle, **off by default**, and use the game’s native XP icon. Their 147 scene placements share a prefab ID, so collection remains unknown. **Attack / defence books** contains only the 28 permanent books.
- The filter panel and tooltips close on map-close, teleport/loading and character-spawn events. Brief map-activation transitions preserve the overlay so markers can resume.
- **Marker tooltips** can be switched off in the F5 Options tab.
- Added a [screenshot gallery](https://github.com/ollieatkinson/castlevania-belmonts-curse-map-secrets/tree/v0.1.2/docs/screenshots).

### Install
Close the game and extract **one** ZIP into the game directory:
- `MapSecrets-v0.1.2.zip` upgrades an existing BepInEx installation.
- `MapSecrets-v0.1.2.standalone.zip` includes BepInEx 6.0.788 for a fresh installation.

Existing settings are retained; the plugin remains `BepInEx/plugins/MapAssist.dll`. Restart the game after installing. On Linux/Proton use `WINEDLLOVERRIDES="winhttp=n,b" %command%` in Steam launch options.

### Validation and coverage
The preview was tested in game before release. The release build passes 87 catalog, save-state and label checks, and all 118 declared native icon/menu references were checked against the installed game assets. Both ZIPs include SHA-256 checksums.

The catalog retains 672 placements across 384 audited rooms and 10 world variants. The 43 uncertain locations remain hidden by default. Some puzzles, objectives, walls, lore and experience sources lack reliable completion signals and may remain visible after completion. Ability-based reachability filtering is not included; the supported game-build hash and other coverage limits are unchanged.
