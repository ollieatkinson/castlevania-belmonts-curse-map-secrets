Compatibility update for Map Secrets.

- Removed the requirement to match the Steam reference build's `GameAssembly.dll` hash. Other builds, including Xbox app on PC, can now attempt to load the mod instead of being blocked at startup.
- Startup logs the game version and actual DLL hash. A different or unreadable hash is a warning and does not disable the mod.
- Map hooks and components load independently, so a failed hook or component does not prevent the others from loading.
- If collection or exploration filtering fails, the map keeps its markers visible. Filtering is retried when you reopen the map.

This addresses the startup hash restriction reported in [the Nexus Mods support thread](https://www.nexusmods.com/castlevaniabelmontscurse/mods/62?tab=posts&comment_id=177863409), including the reported hash `56212abb69646214fecc2385460e94a72c6a0e8ddf03ccecd9ac5228e22cf3d5`. It does not add a hash allowlist or guarantee compatibility with every build. The marker catalog still uses the Steam reference data; Xbox app on PC has not been playtested.

Choose **Plugin** if BepInEx is already installed, or **Standalone** for a fresh installation. Extract the whole ZIP into the main game folder beside the game EXE. Existing settings are preserved. Include `BepInEx/LogOutput.log` when reporting any remaining problems.
