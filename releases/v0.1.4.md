All map shortcuts can now be changed in `BepInEx/config/ollieatkinson.mapassist.cfg`, under `[Hotkeys]`. The menu defaults to **F4** instead of F5. Set a shortcut to `None` to disable it. The menu hints follow your settings.

Experience statues now hide when collected, including those already collected in an existing save. Each statue uses its own room-assigned save ID.

Close the game and extract one ZIP into the game folder. The plugin ZIP updates an existing BepInEx installation; the standalone ZIP includes BepInEx. Existing settings are preserved.
