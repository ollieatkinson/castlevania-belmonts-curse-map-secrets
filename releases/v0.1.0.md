Map Secrets adds configurable collectible and hidden-path markers to the area map in Castlevania: Belmont’s Curse.

### Installation
- **Already have BepInEx 6.0.788?** Extract `MapSecrets-v0.1.0.zip` into the game directory.
- **Fresh install?** Extract `MapSecrets-v0.1.0.standalone.zip` into the game directory; it includes BepInEx.
- Close the game before installing. On Linux/Proton, set Steam launch options to `WINEDLLOVERRIDES="winhttp=n,b" %command%`.
- Upgrades replace `BepInEx/plugins/MapAssist.dll`. Existing Map Assist preview settings are preserved. Install one ZIP, then restart the game.

### Features
- 672 marker placements across the audited world areas and sub-areas.
- Separate toggles and native game icons for health, mana, upgrades, keepsakes, abilities, arcana, relics, weapons, clues, challenges, objectives, puzzles, lore, hidden paths and breakable walls.
- A game-style filter menu: press **F5** on the map. **F6** toggles the overlay; **F7/F8** toggle health/mana; **F10** toggles hidden paths.
- Hide collected items and discovered passages where the game exposes a verified completion state.
- Refresh on room entry and secret discovery, adjustable marker size, optional first-visit bell and persistent configuration.
- Works alongside Mirror Fast Travel without modifying game saves.

### Coverage and limitations
- Audits 384 playable room scenes across 10 world variants, with 447 native placements/reward-room entries and an attributed Gamer Guides reference cross-check.
- 73 of 102 hidden-path references have native persistent discovery links. Resettable ambush/scenery zones are excluded.
- **43 uncertain locations are hidden by default** and can be enabled in Options. Some reference positions and scripted reward markers are approximate.
- Some challenges, puzzles, walls, objectives and previously read lore lack proven completion signals and may remain visible after completion. Unknown states are not guessed.
- Ability-based reachability filtering is not included. The catalog is restricted to the supported game assembly hash; other builds disable the overlay and log the reason.
- The expanded menu and bell have automated/build validation but still need broader in-game testing.

See the README and `data/coverage.json` for details. Thanks to [Gamer Guides](https://www.gamerguides.com/castlevania-belmonts-curse/maps/paris) for the map reference and to the BepInEx project.

Both ZIPs have SHA-256 checksum files. The standalone includes pinned loader dependencies, licenses and corresponding sources; game artwork, fonts and assemblies are loaded from the installed game rather than bundled.
