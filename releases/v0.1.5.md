Installation update for Map Secrets.

- Standalone ZIPs now include `Install.cmd`. Extract the whole ZIP and run it to locate the game folder or select the game EXE. It can copy files out of an accidental nested `BepInEx` installation.
- Added `INSTALL.txt` with the expected folder layout and troubleshooting steps.
- Packaging now verifies the mod's `BepInEx/plugins/MapAssist.dll` path and the required loader files before publishing.

Extract into the main game folder, beside `Castlevania Belmont's Curse.exe`, not inside `BepInEx`. The loose `winhttp.dll` is part of the loader and belongs beside the game EXE. First launch may take a few minutes. If nothing loads, share `BepInEx/LogOutput.log`.

Gameplay is unchanged. Existing configurations, saves and other plugins are preserved by the install helper.
