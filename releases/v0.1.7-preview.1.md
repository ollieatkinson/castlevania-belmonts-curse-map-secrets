Exploration completion fixes and clearer marker tooltips.

- Corrected all 42 native breakable-wall markers to use their individual room save IDs. Previously broken walls can now be recognised without revisiting them when **Hide collected / found** is enabled.
- Ignore shared prefab IDs cached by older mod versions for walls and experience statues, so an old observation file cannot override the correct completion ID.
- Markers without a confirmed completion mapping now say **Completion not tracked**. These can remain visible even on a 100% save. **Completion unknown** is reserved for tracked markers whose current state cannot be determined.
- Lore tracked by the mod says **Read to mark as found** until it has been read with the mod installed.

This is a prerelease for testing. It does not add completion tracking for every Exploration marker. The reporter's exact affected markers and 100% save have not been playtested.

Validation: Release build completed without warnings or errors; 290 regression checks passed. Catalog verification confirmed that only the 42 wall save IDs changed, preserving marker identities and positions.

Choose **Plugin** if BepInEx is already installed, or **Standalone** for a fresh installation. Extract the whole ZIP into the main game folder beside the game EXE. Existing settings are preserved.
